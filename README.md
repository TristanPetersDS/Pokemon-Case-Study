# 🏆 Are Gen-1 Pokémon Really the Best? A Data-Driven Verdict

Welcome! This project tackles one of the Pokémon fandom’s most debated questions:

> _“Is Generation 1 truly the best generation of Pokémon?”_

Using clean data and clear visuals, this Jupyter notebook compares all generations across multiple dimensions to find out if Gen 1 deserves its legendary reputation.

## 📊 Project Highlights

- 📜 Largest Pokédex: Which generation introduced the most Pokémon?
- ✨ Legendary Line-Up: Who has the most Legendaries?
- 🎨 Typing Diversity: Which generation brings the most strategic variety?
- 💪 Stat Strength: Who leads in average power, both regular and Legendary?
- 🔥 Starter Showdown: Which generation has the strongest starters?

## ✅ Tools Used

- Python 3
- Pandas & NumPy
- Seaborn & Matplotlib
- Jupyter Notebook

## 📈 Conclusion

Every generation has its strengths — and the data proves that Gen 1 isn’t always #1. While nostalgia may cloud perception, this analysis reveals a balanced and evolving Pokémon landscape.
